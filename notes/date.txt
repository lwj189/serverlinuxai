1.int main() {
    创建套接字();
    允许端口复用(); // 具体函数忘了，留空
    绑定端口();
    监听();

    while(1) {
        等待客户端连接(); // accept
        读取请求数据();   // read
        发送固定网页();   // send
        关闭连接();       // close
    }
}


2.接受客户端连接;

头部数据 = 循环读数据直到碰到 "\r\n\r\n";

从头部数据中:
  拆出 方法(GET/POST) 和 路径(/submit)；
  找出 Content-Length 的值；

如果 Content-Length > 0:
  循环读数据，直到累计读满 Content-Length 个字节;

如果 方法==GET 且 路径==/:
  返回 200 首页;
否则 方法==POST 且 路径==/submit:
  打印 Body 数据;
  返回 200 成功;
否则:
  返回 404 找不到;

关闭连接;

3.主线程 -> epoll_wait(等待通知) -> 返回 [fd1, fd2, fd3] -> 依次处理 fd1, fd2, fd3 的 read(不卡住) -> 回复 -> 回到 epoll_wait
